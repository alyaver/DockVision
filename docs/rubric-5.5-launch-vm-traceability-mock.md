## Safety and interpretation notes

- No tests referenced in this document should use `WindowsVm/shared` as routine test storage.
- Automated launch tests should use temporary directories, ephemeral ports, and stubbed readiness or external services.
- Browser launch tests may use the real React/Vite client while intercepting API calls; that does not prove live backend, Docker, VM, or guest execution.
- A running container is not sufficient evidence of guest readiness.
- Arbitrary uploaded scripts must not be executed on the development host for rubric verification.
- Fresh commands, dates, tester information, pass/fail counts, and evidence must be recorded before this document is treated as a completed verification report.
